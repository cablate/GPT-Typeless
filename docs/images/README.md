# 截圖放置說明

請將產品截圖放置在此目錄中。

## 截圖規範

### 命名規則

- `screenshot.png` - 主介面截圖
- `settings.png` - 設定面板截圖
- `transcription.png` - 轉錄結果截圖

### 截圖要求

- **尺寸**: 建議寬度 1200px+
- **格式**: PNG（推薦）或 JPG
- **內容**: 顯示完整視窗，包含標題列
- **風格**: 使用明亮背景，避免過度縮放

## 添加步驟

1. 截取應用視窗
2. 調整尺寸並裁剪
3. 保存到此目錄（遵循命名規則）
4. 在 `README.md` 中取消註釋並更新截圖路徑
